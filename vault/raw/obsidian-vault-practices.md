# Obsidian Vault Practices

*Sample source written for this assignment.*

## Vault layout
Open the vault folder itself in Obsidian, not the whole code repository. Keep untouched originals in raw/, reviewed notes in wiki/, and a human landing page called index.md at the vault root.

## Note names
Name notes for their subject in two to six words, such as Retrieval Augmented Generation. Never use hashes, timestamps, or full sentences as filenames, because the filename is the label shown in the graph view.

## Links
Use internal links in double brackets to connect related notes, and say why the link matters. Do not link unrelated notes just to make the graph look busy. The backlinks pane shows which notes point to the current one.

## Graph view
To see only curated notes, filter the graph with the path filter wiki/ and turn off the Attachments toggle. Zoom in until the labels are readable.

## Properties
Machine identifiers and original filenames belong in note properties (front matter), for example a source property that points back to the file in raw/.
