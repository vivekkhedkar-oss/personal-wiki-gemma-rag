# Obsidian Vault Practices

This document outlines best practices for organizing and managing a personal wiki within Obsidian. It provides guidelines on vault layout, note naming, linking, graph view filtering, and using properties.

## Key points

- Open the vault folder itself in Obsidian, not the whole code repository.
- Keep untouched originals in raw/, reviewed notes in wiki/, and a human landing page called index.md at the vault root.
- Name notes for their subject in two to six words.
- Use internal links in double brackets to connect related notes and explain why the link matters.
- Filter the graph view with the path filter wiki/ and turn off the Attachments toggle.
- Machine identifiers and original filenames belong in note properties.
